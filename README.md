# MyWebsite - Agencia de Innovación Digital & Soluciones Tecnológicas

Sitio web oficial estático maquetado en **HTML5**, **CSS3 (Vanilla)** y **JavaScript (Vanilla)**.

## 🚀 Estructura del Proyecto

- `index.html` — Página Principal / Landing Page
- `nosotros.html` — Sección Nosotros (Equipo: Alberto Tejada & Ramses CB)
- `soluciones.html` — Servicios y Soluciones Digitales
- `formulario.html` — Formulario de Solicitud de Proyectos
- `FAQ.html` — Preguntas Frecuentes con buscador interactivo
- `politica.html` — Política de Privacidad
- `terminos.html` — Términos de Servicio
- `styles.css` — Sistema de diseño y hojas de estilo globales
- `script.js` — Lógica de navegación y micro-interacciones
- `assets/` — Recursos multimedia (imágenes, logos SVG, avatares)

## 🛠️ Tecnologías

- **Frontend:** HTML5, CSS3, JavaScript ES6+
- **Estilos:** Vanilla CSS con variables CSS, glassmorphism y micro-animaciones
- **Despliegue:** Estático (Vercel / GitHub Pages)
